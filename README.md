# 🏦 KhanSarafi - Currency Exchange & Hawala Management System

A professional Currency Exchange and Hawala Management System developed with Laravel 10. The application helps exchange companies manage customers, currencies, exchange rates, cash balances, hawala transactions, and daily financial operations through an easy-to-use dashboard.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/KhanSarafi.git
```

## Enter Project

```bash
cd KhanSarafi
```

## Install Dependencies

```bash
composer install
npm install
```

## Environment Setup

```bash
cp .env.example .env
```

Generate Application Key:

```bash
php artisan key:generate
```

Configure Database Settings in:

```env
DB_DATABASE=khansarafi
DB_USERNAME=root
DB_PASSWORD=
```

Run Migrations:

```bash
php artisan migrate
```

Run Development Server:

```bash
php artisan serve
```

Compile Assets:

```bash
npm run dev
```
